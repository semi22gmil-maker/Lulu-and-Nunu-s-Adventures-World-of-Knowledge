# سلامة الطفل الرقمية — CHILD SAFETY STANDARDS

يخضع تصميم كل شاشة وعالم وميزة في **مغامرات لولو ونونو** للقواعد الملزمة التالية:

1. **منع الإعلانات والروابط الخارجية:** لا إعلانات، لا عروض ربحية، ولا روابط تخرج الطفل من اللعبة إلى المتصفح (`window.open` ممنوع).
2. **منع المشتريات العشوائية:** العملات داخل اللعبة تُكسب بالتعلم فقط ولا ترتبط بأي بوابة دفع أو مال حقيقي.
3. **منع التواصل غير الآمن:** لا غرف دردشة، لا لوحات صدارة علنية بأطفال حقيقيين، ولا مشاركة رسومات على الإنترنت.
4. **بوابة الوالدين (`Parent Gate`):** كل إجراء يؤثر على الإعدادات، الحد اليومي للعب، أو حذف البيانات محمي بتحدٍّ حسابي/PIN يمنع الأطفال الصغار من تعديله عرضاً.
5. **الرفق التربوي وتجنب الضغوط السلبية:** لا شاشات خسارة قاسية ولا موقتات عقابية؛ عند الخطأ تستجيب لولو أو نونو بتشجيع هادئ وتلميح مساعد.
6. **توجيه عمر مناسب (4–10 سنوات):** نصوص عربية سليمة، محتوى خالٍ من العنف أو المخاوف البصرية، وتباين واضح يحمي البصر مع دعم خيار تقليل الحركة (`reducedMotion`).
