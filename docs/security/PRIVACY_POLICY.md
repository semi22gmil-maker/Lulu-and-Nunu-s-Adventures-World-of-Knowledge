# سياسة الخصوصية — PRIVACY POLICY (مسودة تطبيقية)

**اسم التطبيق:** مغامرات لولو ونونو – عالم المعرفة (`com.lulunono.adventure`)  
**آخر تحديث:** 2026-11-17

---

## 1. التزامنا الصارم بخصوصية الأطفال
نحن نلتزم بحماية خصوصية الأطفال وفق مبادئ **COPPA** و**GDPR-K** و**Google Play Families Policy**. يعمل التطبيق بنموذج **محلي أولاً دون اتصال (`Local-First / Offline-First`)**:

1. **لا نجمع ولا ننقل أي بيانات شخصية (`Zero PII Transmission`):**
   - الاسم الأول للطفل، العمر، الشخصية المفضلة، التقدم التعليمي، والرسومات المحفوظة تبقى **حصرياً على جهاز المستخدم فقط** داخل `IndexedDB` و`localStorage`.
   - لا يمتلك التطبيق خادماً خلفياً لاستلام بيانات المستخدمين ولا يرسل أي بيانات تحليلية أو سلوكية عبر الإنترنت.

2. **لا إعلانات ولا تتبع:**
   - لا يحتوي التطبيق على أي إعلانات، أو معرّفات إعلانية (`Ad ID`)، أو أدوات تتبع مواقع (`GPS`), أو دردشة بين المستخدمين.

3. **أذونات الجهاز:**
   - لا يطلب التطبيق الوصول إلى الكاميرا، الميكروفون، جهات الاتصال، الموقع الجغرافي، أو الرسائل.
   - يستخدم فقط التخزين المحلي في المتصفح/WebView وتشغيل الصوت عبر الجهاز.

4. **تحكم ولي الأمر وحق الحذف:**
   - يستطيع ولي الأمر عبر **بوابة الوالدين المحمية** عرض سجل النشاط المحلي، تعديل الإعدادات، تصفير التقدم، أو حذف ملف الطفل بالكامل فوراً من الجهاز.

5. **ملاحظة حول الخطوط في مرحلة التطوير الحالية:**
   - حالياً يحمل `index.html` خطي `Cairo` و`Tajawal` عبر `fonts.googleapis.com` وتخزينهما عبر `sw.js`؛ ومن المخطط في المرحلة 14 تضمين الخطوط محلياً داخل التطبيق لإلغاء أي اتصال خارجي تماماً عند النشر النهائي.
