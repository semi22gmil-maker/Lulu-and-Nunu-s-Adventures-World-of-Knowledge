# حماية البيانات المحلية — DATA PROTECTION

## 1. جرد البيانات المخزنة على جهاز المستخدم
| البيانات | موقع التخزين | الحساسية | طريقة التعديل أو الحذف |
|---|---|---|---|
| ملف الطفل (الاسم المستعار، العمر، التقدم، النجوم، الأوسمة، الأزياء) | `IndexedDB -> profiles` | متوسطة (محلية) | من `ProfileScreen` أو `ParentDashboardScreen` |
| سجل المحاولات والمهارات | `IndexedDB -> activity_logs` | تعليمية محلية | يُحذف تلقائياً مع حذف الملف أو تصفيره من لوحة الوالدين |
| رسومات الطفل (`DataURL`) | `IndexedDB -> drawings` | محلية | يحذفها الطفل/الوالد من المعرض أو عند حذف الملف |
| إعدادات الصوت والجودة والحد اليومي وPIN | `localStorage -> lulu_nono_v1_settings` | إعدادات محلية | من `ParentDashboardScreen` المحمية ببوابة الوالدين |

## 2. ضوابط الحماية والصيانة
- **منع التسريب عبر السجلات (`Logs`):** عدم طباعة أسماء الأطفال أو رمز PIN في `console.log`.
- **تقييد سعة اللوحات والبيانات:** عند تفعيل عالم الفن (المرحلة 9)، يتم ضغط `Canvas DataURL` لتفادي امتلاء مساحة المتصفح (`QuotaExceededError`).
- **تشفير رمز PIN المخطط:** ترقية `parentPinHash` من نص خام مؤقت حالياً إلى `SHA-256` عبر `Web Crypto API` في المرحلة 14 (انظر `KNOWN_ISSUES.md`).
