# معايير اعتماد المراحل ودورة القبول — ACCEPTANCE CRITERIA

يُحظر تماماً الخلط بين كتابة الكود وبين اعتماد المرحلة. تتبع كل مرحلة من المراحل الـ 17 **دورة القبول الصارمة ذات الـ 17 خطوة**:

---

## أ. دورة الاعتماد الإلزامية لكل مرحلة (17 خطوة)

1. قراءة وثيقة المرحلة في `docs/phases/PHASE_XX_*.md` والتأكد من تحقق كافة اعتمادياتها.
2. مراجعة `CURRENT_PROJECT_STATE.md` و`KNOWN_ISSUES.md` قبل كتابة أي سطر كود.
3. تنفيذ جميع المهام التقنية ضمن نطاق المرحلة المحدد فقط (دون التجاوز إلى مراحل لاحقة).
4. الالتزام بمعايير الكود والأمان والسلامة الرقمية للأطفال (`RTL`، 0 إعلانات، 0 روابط خارجية).
5. فحص سلامة الأنواع عبر `npm run lint` (`tsc --noEmit`: 0 أخطاء).
6. فحص بناء الإنتاج عبر `npm run build` (`vite build`: 0 أخطاء).
7. التحقق من عدم وجود أخطاء في `Console` أو `PageError` أو طلبات شبكة فاشلة.
8. تنفيذ اختبارات الوحدة/التكامل للأنظمة المعدلة أو المضافة.
9. كتابة/تحديث اختبارات Playwright E2E المخصصة للمرحلة في `tests/phaseXX/`.
10. تشغيل حزمة اختبارات Playwright الخاصة بالمرحلة فعلياً من البداية إلى النهاية دون اختصار.
11. التحقق من عمل الميزة في وضع **العمل دون إنترنت (`Offline / Service Worker`)** ومراجعة حفظ `IndexedDB`/`localStorage`.
12. فحص التجاوب واللمس على شاشة الجوال (`390×844 RTL`) وسطح المكتب (`1440×960`).
13. التقاط ومراجعة لقطات الشاشة الفعلية في `reports/phaseXX/screenshots/`.
14. توليد ملف النتائج المنظم `reports/phaseXX/qa-results.json`.
15. كتابة تقرير الجودة الصادق `reports/phaseXX/PHASEXX_QA_REPORT.md` مع الإبلاغ عن أي بنود `NOT TESTED` أو `INCOMPLETE`.
16. تحديث حالة المرحلة في `PROJECT_STATUS.md` و`docs/handover/CURRENT_PROJECT_STATE.md` و`SESSION_LOG.md` وتوثيق الدفع/التسليم إلى GitHub.
17. **الانتظار وعدم الانتقال للمرحلة التالية** إلا بعد توفر كافة الأدلة أعلاه والموافقة الصريحة.

---

## ب. التمييز الإلزامي بين مستويات الإنجاز في `PROJECT_STATUS.md`

| التوصيف | المعنى الدقيق |
|---|---|
| `Code Implemented` | الملفات والشاشات مبرمجة في `src/` لكن لم تُستكمل اختبارات القبول الرسمية بعد |
| `Locally Tested` | شُغّلت فحوص جزئية أو يدوية محلياً دون إغلاق حزمة الانحدار/التقرير الكامل |
| `Automated Tests Passed` | اجتازت حزمة Playwright/CI بالكامل وصدرت ملفات `qa-results.json` كاملةً |
| `GitHub Verified` | رُفعت التعديلات ودُقّقت على مستودع GitHub الرسمي (`CI Green`) |
| `User Approved` / `APPROVED` | اعتُمدت المرحلة رسمياً وسُمح بالانتقال للمرحلة التالية |
