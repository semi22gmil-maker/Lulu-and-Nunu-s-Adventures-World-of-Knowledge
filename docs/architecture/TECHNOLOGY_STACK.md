## 2. مكتبات موجودة في `package.json` غير مستخدمة داخل `src/`
خلال فحص `grep` على المجلد `src/` و`public/` وُجدت التبعيات التالية موروثة من قالب البيئة الأساسية ولم تُستدعَ في كود التطبيق حتى الآن:
- `@google/genai` (`^2.4.0`) — غير مستخدم (اللعبة حالياً محلية بالكامل دون استدعاءات AI في وقت التشغيل).
- `express` (`^4.21.2`) + `@types/express` + `dotenv` — غير مستخدم (لا يوجد `server.ts` أو مسارات API خلفية).

> **ملاحظة:** يجب عدم حذف هذه الحزم عشوائياً دون مراجعة توافقها مع بيئة النشر أو قبل المرحلة 14 (تنظيف التبعيات وتحسين الحزمة).

## 3. تقنيات المتصفح القياسية المستخدمة بدون حزم إضافية
- **`Web Audio API`:** توليد المؤثرات الصوتية غير الكلامية (`src/audio/audioManager.ts`).
- **`IndexedDB API`:** تخزين ملفات الأطفال وسجلات المحاولات واللوحات الفنية (`src/storage/indexedDbService.ts`).
- **`localStorage API`:** حفظ الإعدادات السريعة وحالة القصة (`src/storage/localStorageService.ts`).
- **`Service Worker` + `Web App Manifest`:** التخزين للعمل دون إنترنت (`public/sw.js`, `public/manifest.webmanifest`).
- **الخطوط:** `Cairo` و`Tajawal` محمّلة عبر Google Fonts في `index.html` ومخزنة مؤقتاً عبر `sw.js`.
