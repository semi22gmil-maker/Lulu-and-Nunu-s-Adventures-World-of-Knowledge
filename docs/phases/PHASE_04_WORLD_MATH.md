# المرحلة 04: عالم الأرقام والحساب (`PHASE_04_WORLD_MATH`)

**الحالة الحالية:** `PLANNED — Not implemented`

## 1. اسم المرحلة
بناء عالم الأرقام والحساب (`Numbers & Math World`) — **نجمة الحساب**

## 2. رقم المرحلة
المرحلة 4 (`Phase 04`)

## 3. الهدف الرئيسي
بناء الأنشطة التفاعلية العملية الخمسة لعالم الأرقام والحساب (`math-1` إلى `math-5`) لتنمية مهارات العد والجمع والطرح والمقارنة والهندسة والأنماط.

## 4. وصف المرحلة
تقديم الرياضيات بصرياً عبر العناصر المحسوسة (جمع التفاح في السلة، سلة الطرح، ميزان المقارنة، الأشكال الهندسية، والأنماط العددية) مع تكييف نطاق الأرقام حسب مستوى الصعوبة (1–10 للمبتدئ، 1–20 للمتوسط، حتى 50–100 للمتقدم).

## 5. المتطلبات السابقة
- اعتماد المرحلة 2 (ويفضّل بعد المرحلة 3 لتوحيد أنماط الأنشطة التفاعلية).

## 6. المهام التفصيلية
1. بناء `math-1` (**جمع التفاح**): عدّ وإضافة عناصر للسلة مع عدّاد مرئي تفاعلي.
2. بناء `math-2` (**سلة الطرح**): إزالة عدد محدد من العناصر ومراقبة الباقي.
3. بناء `math-3` (**ميزان المقارنة**): مقارنة الكفتين (`أكبر` / `أصغر` / `يساوي`) بتفاعل ميلان الميزان.
4. بناء `math-4` (**الأشكال الهندسية**): تمييز الدائرة والمربع والمثلث والمستطيل والنجمة وتصنيفها.
5. بناء `math-5` (**الأنماط والترتيب**): إكمال التسلسل العددي أو البصري وترتيب الأرقام تصاعدياً وتنازلياً.
6. تفعيل `implemented: true` لعالم `NumbersMath` في `worldRegistry.ts`.

## 7. الملفات والمكونات المتوقع إنشاؤها أو تعديلها
