# المرحلة 08: عالم اللغة الإنجليزية (`PHASE_08_WORLD_ENGLISH`)

**الحالة الحالية:** `PLANNED — Not implemented`

## 1. اسم المرحلة
بناء عالم اللغة الإنجليزية (`English World`) — **نجمة اللغات**

## 2. رقم المرحلة
المرحلة 8 (`Phase 08`)

## 3. الهدف الرئيسي
تقديم أساسيات اللغة الإنجليزية للطفل العربي بطريقة محببة وبسيطة عبر المراحل الثلاث (`en-1` إلى `en-3`).

## 4. وصف المرحلة
تعليم حروف الإنجليزية (`A–Z`) وربطها بصور وكلمات مألوفة، تعليم الأرقام والألوان الأساسية بالإنجليزية مع دعم الشرح العربي عند الحاجة، ومطابقة الكلمات الحيوانية واليومية البسيطة.

## 5. المتطلبات السابقة
- اعتماد المرحلة 2 (ويفضَّل الاستفادة من نمط الحروف في المرحلة 3).

## 6. المهام التفصيلية
1. بناء معجم إنجليزي ميسر للأطفال (26 حرفاً + أرقام 1–20 + 10 ألوان + 20 كلمة أساسية).
2. بناء `en-1` (**حروف A-Z**): استكشاف الحروف الكبيرة والصغيرة ومطابقتها بالصور.
3. بناء `en-2` (**الأرقام والألوان**): تحديات تلوين وعدّ تفاعلية ثنائية اللغة.
4. بناء `en-3` (**الحيوانات والكلمات**): ربط الكلمة الإنجليزية المنطوقة/المكتوبة بالصورة والمعنى.
5. ضبط حاويات `dir="ltr"` للكلمات والجمل الإنجليزية داخل الواجهة العربية `RTL` لمنع انعكاس الحروف.
6. تفعيل `implemented: true` لعالم `EnglishWorld` في `worldRegistry.ts`.

## 7. الملفات والمكونات المتوقع إنشاؤها أو تعديلها
- `src/worlds/english-world/` (المعجم + 3 أنشطة تفاعلية)
- `src/registry/worldRegistry.ts`, `src/screens/GameplayScreen.tsx`
- `tests/phase8/english-world.spec.ts`, `reports/phase8/PHASE8_QA_REPORT.md`

## 8. التقنيات المستخدمة
React 19, TypeScript, Tailwind RTL/LTR isolation (`unicode-bidi`), Three.js (`CharacterCanvas`), `audioManager` / `voiceManifest`.
