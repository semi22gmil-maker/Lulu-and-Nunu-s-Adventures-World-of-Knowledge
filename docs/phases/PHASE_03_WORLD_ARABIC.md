# المرحلة 03: عالم الحروف واللغة العربية (`PHASE_03_WORLD_ARABIC`)

**الحالة الحالية:** `PLANNED — Not implemented`

## 1. اسم المرحلة
بناء عالم الحروف واللغة العربية (`Arabic Letters World`) — **نجمة البيان**

## 2. رقم المرحلة
المرحلة 3 (`Phase 03`)

## 3. الهدف الرئيسي
استبدال الأنشطة الهيكلية المؤقتة لعالم الحروف العربية بمنهج تعليمي تفاعلي متكامل يغطي الـ 28 حرفاً عبر المراحل الست المسجلة في `worldRegistry.ts` (`ar-1` إلى `ar-6`).

## 4. وصف المرحلة
تطوير الأنشطة التربوية الستة لعالم الحروف العربية داخل `GameplayScreen` عبر وحدة عالم مستقلة (`src/worlds/arabic-letters/`) وتفعيل `implemented: true` للعالم الأول في `worldRegistry.ts`.

## 5. المتطلبات السابقة
- اعتماد المرحلة 2 بالكامل (`PHASE2_QA_REPORT.md`).

## 6. المهام التفصيلية
1. بناء بنك الحروف العربية الـ 28 مع الكلمات المصاحبة والحركات (فتحة، ضمة، كسرة) وأشكال الحرف (أول/وسط/آخر/منفصل).
2. بناء مرحلة `ar-1` (**مزرعة الكلمات**): لمس عناصر رسومية/تفاعلية واكتشاف أسمائها وحرفها الأول.
3. بناء مرحلة `ar-2` (**صيد الحروف**): التقاط الحرف المستهدف من عناصر متحركة مع تجنب التشتيت المفرط.
4. بناء مرحلة `ar-3` (**تتبع الحروف**): لوحة Canvas لمسية لكتابة الحرف بالإصبع على مسار مضيء مع تقييم الدقة.
5. بناء مرحلة `ar-4` (**أشكال الحروف**): مطابقة شكل الحرف بحسب موقعه في الكلمة.
6. بناء مرحلة `ar-5` (**تركيب الكلمات**): سحب/نقر ترتيب الحروف لتكوين كلمات ثلاثية وبسيطة.
7. بناء مرحلة `ar-6` (**تحديات صوتية**): تمييز الحرف والمقطع المرتبط بالصوت/البطاقة.
8. ربط تفاعلات لولو ونونو (`Encourage`, `Celebrate`, `GentleSad`, `Think`) بكل محاولة وتسجيل المهارات في `activity_logs`.

## 7. الملفات والمكونات المتوقع إنشاؤها أو تعديلها
- `src/worlds/arabic-letters/` (البيانات + 6 مكونات مراحل + محرك التوليد التكيفي للأسئلة)
- `src/registry/worldRegistry.ts` (تحديث `implemented: true` للعالم 1)
- `src/screens/GameplayScreen.tsx` (توجيه العالم 1 للوحدة الحقيقية بدلاً من `phase2Activities.ts`)
- `tests/phase3/arabic-world.spec.ts` و`reports/phase3/PHASE3_QA_REPORT.md`

## 8. التقنيات المستخدمة
React 19, TypeScript, HTML5 Canvas (لتتبع الحروف), Pointer Events (`RTL`-safe), Three.js (`CharacterCanvas`), `audioManager`.

## 9. الوظائف المطلوبة

## 10. المتطلبات الأمنية
