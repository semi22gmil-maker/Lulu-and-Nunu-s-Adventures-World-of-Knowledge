# المرحلة 12: لوحة الوالدين وحماية الطفل (`PHASE_12_PARENT_DASHBOARD`)

**الحالة الحالية:** `IN PROGRESS` *(البوابة الحسابية/PIN، عرض السجلات الأولي، وضوابط الصوت والجودة مدمجة في المرحلة 2؛ التحليلات التربوية المفصلة وفرض الحد الزمني الحي مؤجلان هنا)*

## 1. اسم المرحلة
استكمال لوحة تحكم الوالدين، التقارير التربوية، وضوابط الوقت (`Parent Dashboard & Child Safety Controls`)

## 2. رقم المرحلة
المرحلة 12 (`Phase 12`)

## 3. الهدف الرئيسي
توفير لوحة متكاملة لولي الأمر تعرض تقارير الإتقان حسب العالم والمهارة من بيانات `IndexedDB` الحقيقية، وتُفعّل الإنفاذ الحي للحد اليومي للعب (`dailyLimitMinutes`) وإدارة نسخ/تصدير/حذف البيانات محلياً.

## 4. وصف المرحلة
توسيع `ParentDashboardScreen.tsx` و`ParentGateScreen.tsx` لتقديم تحليلات واضحة غير مضللة، وعداد زمن جلسة فعلي ينبه الطفل بلطف عبر لولو ونونو عند انتهاء الوقت اليومي ولا يسمح باستئناف اللعب إلا بإذن عبر بوابة الوالدين.

## 5. المتطلبات السابقة
- اعتماد المراحل 2 و10 و11.

## 6. المهام التفصيلية
1. تفعيل عداد وقت اللعب اليومي (`dailyLimitMinutes`) في `gameStore.tsx` وربطه بشاشة استراحة لطيفة عند انتهاء الوقت.
2. عرض رسوم ومؤشرات تقدم حقيقية لكل عالم ومهارة من `activity_logs` (دون أي أرقام وهمية إذا كانت السجلات فارغة).
3. تحسين بوابة الوالدين بمؤقت قفل مؤقت عند تكرار المحاولات الخاطئة وتشفير رمز PIN.
4. إضافة تصدير تقرير تقدم محلي بصيغة JSON/طباعة آمنة إن رغب ولي الأمر (دون إرساله للشبكة).

## 7. الملفات والمكونات المتوقع إنشاؤها أو تعديلها
- `src/screens/ParentDashboardScreen.tsx`, `src/screens/ParentGateScreen.tsx`
- `src/components/modals/TimeLimitReachedModal.tsx` (أو شاشة استراحة مدمجة)
- `src/state/gameStore.tsx`
- `tests/phase12/parent-controls.spec.ts`, `reports/phase12/PHASE12_QA_REPORT.md`

## 8. التقنيات المستخدمة
React 19, TypeScript, IndexedDB (`activity_logs`, `profiles`), Web Crypto API (لـ PIN), Tailwind CSS RTL.

## 9. الوظائف المطلوبة
- فرض بوابة الوالدين، تقييد وقت اللعب عند التفعيل، عرض أخطاء وسرعة وإتقان كل مجال تربوي، وإمكانية تصفير أو حذف الملف.

## 10. المتطلبات الأمنية
- عدم تخزين رمز PIN كنص صريح؛ عدم السماح بتجاوز شاشة انتهاء الوقت عبر تحديث الصفحة (`page.reload`) بحفظ الوقت اليومي المستهلك لكل تاريخ يومي.

## 11. اختبارات الوحدة
- اختبار حساب إجمالي دقائق اللعب لليوم الحالي ومنع استمرار اللعب عند تجاوز `dailyLimitMinutes`.

## 12. اختبارات التكامل
- التحقق من استمرارية عداد الوقت اليومي عبر `reload` وتطابق إحصائيات لوحة الوالدين مع سجلات `IndexedDB` الحقيقية.

## 13. اختبارات الواجهة
- Playwright E2E لاختبار PIN الخاطئ والصحيح، ضبط الحد اليومي، وظهور شاشة انتهاء الوقت، وحذف ملف.

## 14. اختبارات Offline عند الحاجة
- عمل لوحة الوالدين وتقاريرها بالكامل بدون إنترنت.

## 15. معايير قبول المرحلة
- 0 أرقام وهمية في التقارير، إنفاذ حقيقي للحد الزمني، ومرور جميع اختبارات الأمان والوالدين.

## 16. الأدلة المطلوبة
