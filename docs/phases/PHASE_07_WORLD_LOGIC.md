## 6. المهام التفصيلية
1. بناء `puz-1` (**تركيب الصور**): شبكة قطع قابلة للنقر/التبديل أو التثبيت لتكوين لوحة مكتملة (2×2 للمبتدئ، 3×3 للمتوسط/المتقدم).
2. بناء `puz-2` (**بطاقات الذاكرة**): قلب البطاقات ومطابقة الأزواج بأقل عدد محاولات ممكن.
3. بناء `puz-3` (**اكتشاف الاختلافات**): مقارنة مشهدين SVG وتحديد مواقع الاختلاف بدقة لمسية مريحة.
4. بناء `puz-4` (**ألغاز المنطق والأنماط**): إكمال المصفوفات والتسلسلات البصرية والعلاقات المنطقية.
