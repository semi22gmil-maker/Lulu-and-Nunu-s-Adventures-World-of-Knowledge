# المرحلة 14: تحسين الأداء وتشديد الأمان (`PHASE_14_PERFORMANCE_SECURITY`)

## 1. اسم المرحلة
تحسين الأداء، تقسيم الحزمة البرمجية، وتشديد الأمان (`Performance Optimization & Security Hardening`)

## 2. رقم المرحلة
المرحلة 14 (`Phase 14`)

## 3. الهدف الرئيسي
تقليص زمن التحميل الأولي وحجم حزمة JavaScript (`Code Splitting`)، تضمين الخطوط العربية محلياً لتفادي الاعتماد الشبكي، وتشديد الإجراءات الأمنية والتبعيات قبل الاختبار النهائي.

## 4. وصف المرحلة
معالجة تحذير Vite الحالي (`index-*.js > 1.3 MB`) بتقسيم Three.js والشاشات والعوالم إلى حزم تُحمَّل عند الحاجة (`React.lazy` + `manualChunks`)، استبدال الاعتماد الخارجي الوحيد (`fonts.googleapis.com`) بخطوط محلية مضمنة، تشديد تشفير رمز الوالدين PIN، ومراجعة الاعتماديات غير المستخدمة.

## 5. المتطلبات السابقة
- اكتمال كافة الميزات الوظيفية في المراحل 0–13.

## 6. المهام التفصيلية
1. تطبيق `React.lazy` و`Suspense` للشاشات والعوالم الـ 7 وضبط `build.rollupOptions.output.manualChunks` في `vite.config.ts`.
2. تضمين خطي `Cairo` و`Tajawal` بصيغة `woff2` محلياً داخل `public/fonts/` وتحديث `index.html` و`sw.js`.
3. مراجعة الاعتماديات غير المستخدمة في `package.json` (`@google/genai`, `express`, إلخ) وتنظيف أي بقايا غير لازمة وفق بيئة النشر.
4. تطبيق تجزئة `SHA-256` لرمز الوالدين PIN عبر `Web Crypto API` وإضافة ترويسة أمان CSP مناسبة في `index.html`.
5. ضبط سقف الذاكرة والرسوميات لاستهلاك مثالي للبطارية على الأجهزة الاقتصادية.

## 7. الملفات والمكونات المتوقع إنشاؤها أو تعديلها
