# إعداد بيئة التطوير — DEVELOPMENT SETUP

## المتطلبات الأساسية
- **Node.js:** `v20+` (مختبر على `v22.23.2`)
- **npm:** `v10+` (مختبر على `10.9.8`)
- **المتصفح والاختبار:** Chromium via Playwright لاختبار WebGL / RTL / Offline
- **للتغليف إلى Android لاحقاً (المرحلة 16 فقط):** Android Studio + JDK 17/21 + Android SDK + Gradle (غير مطلوبة لتطوير الويب حتى المرحلة 15)

## متغيرات البيئة (`.env.example`)
لا يتطلب التطبيق حالياً أي مفاتيح API خارجية للعمل؛ جميع أنظمة التخزين والـ 3D والصوت تعمل محلياً في المتصفح.
