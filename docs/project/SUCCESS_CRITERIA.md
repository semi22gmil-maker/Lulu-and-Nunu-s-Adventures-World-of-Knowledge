# معايير نجاح المشروع — SUCCESS CRITERIA

لا يُعد المشروع ناجحاً بالاكتمال النظري أو المظهر السطحي فقط، بل بتحقيق المعايير الكمية والنوعية التالية:

## 1. معايير النجاح التقنية
- **صفر أخطاء بناء وأنواع:** نجاح `npm run lint` (`tsc --noEmit`) و`npm run build` (`vite build`) في كل مرحلة.
- **ثبات ذاكرة WebGL:** `0` تسرب في `BufferGeometry` و`Textures` عند تركيب وفك الشاشات ثلاثية الأبعاد (متحقَّق في المرحلة 1: `74 === 74` هندسية، `8 === 8` نسيج).
- **اعتمادية الاختبارات التلقائية:** اجتياز حزم Playwright لجميع المراحل المكتملة بدون أخطاء `console.error` أو `pageerror` أو `requestfailed`.
- **حجم تحميل متزن:** تقسيم الحزمة (`Code Splitting`) في المرحلة 14 لتفادي تحميل كامل المنطق قبل الشاشة الأولى.

## 2. معايير تجربة المستخدم (UX & RTL)
- **تجاوب كامل:** خلو الشاشات من التجاوز الأفقي (`scrollWidth <= innerWidth`) على الجوال (`390×844`) والتابلت (`768×900`) وسطح المكتب (`1440×960`).
- **إتاحة اللمس:** أزرار أساسية لا تقل عن `44×44 px` مع تباين واضح واتساق تام في `dir="rtl"`.
- **ثبات Offline:** قدرة الطفل على إكمال اللعب وحفظ التقدم وإعادة فتح التطبيق بدون إنترنت عبر `Service Worker` و`IndexedDB`.

## 3. معايير النجاح التربوية وسلامة الطفل
- **تنفيذ حقيقي للعوالم السبعة:** احتواء كل عالم على أنشطته التفاعلية التربوية المخصصة (المراحل 3–9) وليس نصوصاً استبدالية.
- **خلو تام من المخاطر:** `0` إعلانات، `0` متتبعات سلوكية، `0` نوافذ محظورة (`window.alert`/`window.open`), وتأمين كامل لبوابة الوالدين.

## 4. معايير الجاهزية للنشر (Android / Google Play)
- تغليف ناجح عبر Capacitor وتوقيع حزمة إصدار `AAB` واختبار الأداء الفعلي (`>= 30 FPS`) وحرارة البطارية واللمس والصوت على أجهزة Android حقيقية.
