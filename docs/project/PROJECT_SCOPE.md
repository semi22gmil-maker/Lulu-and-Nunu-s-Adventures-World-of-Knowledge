# نطاق المشروع وحدوده — PROJECT SCOPE

## 1. ما يدخل ضمن نطاق المشروع (In Scope)
1. **البنية التحتية والتطبيق الأساسي:** React + TypeScript + Vite + Three.js + Tailwind RTL + IndexedDB + localStorage + Service Worker + Capacitor config.
2. **الشخصيات ثلاثية الأبعاد:** لولو ونونو، نظام الحركات الـ 13، نظام التعبيرات الـ 8 وحركة الفم، التفاعلات الثنائية الـ 9، ومختبر الشخصيات (`?mode=character-lab`).
3. **التدفق الرئيسي والشاشات الـ 14:** البداية، القصة، إنشاء الملف، الرئيسية، خريطة العوالم، تفاصيل العالم، اختيار المرحلة، اللعب، الفوز، استعادة النجمة، المكافآت، الملف الشخصي، بوابة الوالدين، ولوحة الوالدين.
4. **سبعة عوالم تعليمية كاملة (المراحل 3–9):** الحروف العربية، الأرقام والحساب، مملكة الحيوانات، العلوم والاكتشاف، الذكاء والألغاز، اللغة الإنجليزية، والفن والإبداع (مع حفظ اللوحات محلياً).
5. **المكافآت والذكاء التكيفي ولوحة الوالدين:** XP، عملات، مستويات، أوسمة، أزياء، تتبع المهارات، تعديل الصعوبة، وإعدادات الوقت والجودة.
6. **الجودة والتغليف:** اختبارات Playwright وUnit/Integration وتجهيز Capacitor Android وبناء حزمة الإصدار.

---

## 2. ما هو خارج نطاق المشروع صراحةً (Out of Scope)
لتجنب توسع النطاق أو تعريض سلامة الأطفال للخطر، **يُمنع إدراج الآتي في التطبيق**:
- **أي نوع من الإعلانات التجارية (`Ads` / `AdMob`)** أو حزم التتبع التسويقي (`Analytics` / `Trackers`).
- **نظام دردشة، تعليقات عامة، أو تواصل بين مستخدمين عبر الإنترنت.**
- **مشتريات داخل التطبيق (`In-App Purchases`) أو بوابات دفع عشوائية.**
- **تسجيل دخول عبر شبكات التواصل أو جمع بيانات تعريف شخصية على خوادم (`PII Cloud Storage`).**
- **طلبات تحديد الموقع الجغرافي (`GPS / Geolocation`) أو الوصول للكاميرا/الميكروفون غير المبرر.**
- **توليد محتوى عشوائي غير مراقب عبر الذكاء الاصطناعي أثناء لعب الطفل (AI Chatbot inside child gameplay).**
- **بناء نسخ iOS أو Desktop Native في الخطة الحالية** (التركيز على Web PWA ثم Android عبر Capacitor).
