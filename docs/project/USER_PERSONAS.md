# شخصيات المستخدمين — USER PERSONAS

## 1. الطفل في المرحلة المبكرة (4 – 6 سنوات)
- **المثال التمثيلي:** سارة (5 سنوات)، لا تجيد القراءة السريعة بعد.
- **الاحتياجات:**
  - أزرار كبيرة واضحة ذات أيقونات وألوان مميزة.
  - توجيه صوتي وبصري واضح (لولو ونونو يشيران ويشجعان).
  - مستوى مبتدئ (`Beginner`) يركز على التعرّف، العد البسيط، والألوان.
  - عدم وجود عقوبة قاسية عند الخطأ، بل تشجيع لطيف (`GentleSad` ثم `Encourage`).
- **الأولوية التصميمية:** تقليل النصوص الطويلة، تعظيم التفاعل اللمسي المباشر، وتشغيل النطق عند التوجيه (المرحلة 13).

---

## 2. الطفل في المرحلة التأسيسية والمتوسطة (7 – 10 سنوات)
- **المثال التمثيلي:** كريم (8 سنوات)، يقرأ العربية ولديه فضول علمي ومنطقي.
- **الاحتياجات:**
  - تحديات متدرجة الصعوبة (`Intermediate` ثم `Advanced`) لا تصيبه بالملل.
  - نظام أهداف واضح: جمع العملات الذهبية، فتح الأزياء، جمع الأوسمة الستة، واستعادة النجوم السبع.
  - عوالم العلوم والذكاء واللغة الإنجليزية بمستوى أعمق.
- **الأولوية التصميمية:** استجابة فورية، تتبع دقيق للنقاط والمهارات، وتقديم ألغاز وتجارب تفاعلية ممتعة.

---

## 3. ولي الأمر (الأم / الأب / المربي)
- **المثال التمثيلي:** أم كريم (34 سنة)، تبحث عن بديل عربي آمن للتطبيقات المليئة بالإعلانات.
- **الاحتياجات:**
  - الاطمئنان التام لعدم وجود إعلانات أو روابط خارجية أو دردشة أو تتبع.
  - إنشاء ملف مستقل لكل طفل على نفس الجهاز.
  - معرفة مستوى الطفل ونقاط قوته وضعفه من خلال سجل النشاط الفعلي.
  - التحكم بالصوت، تقليل الحركة، الجودة الرسومية (لتناسب الهاتف)، وتحديد وقت اللعب اليومي.
- **الأولوية التصميمية:** حماية الإعدادات عبر **بوابة الوالدين (`ParentGate`)** ورمز PIN اختياري، وعرض تقارير واضحة وسهلة القراءة.
