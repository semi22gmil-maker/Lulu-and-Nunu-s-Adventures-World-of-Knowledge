## 2. المتطلبات غير الوظيفية (`Non-Functional Requirements`)

| الفئة | المعيار المطلوب | آلية التحقق | الحالة |
|---|---|---|---|
| **اللغة والاتجاه** | دعم عربي كامل `lang="ar" dir="rtl"` في جميع الشاشات دون تداخل نصوص أو تمرير أفقي (`scrollWidth <= innerWidth`) | Playwright `390×844` و`1440×960` | `COMPLETED — Verified` (للمرحلة 1 ومبني للمرحلة 2) |
| **الأداء والذاكرة** | عدم وجود تسرب في `WebGLBufferGeometry` / `Textures`، ودعم 3 مستويات جودة (`low/medium/high`)، وهدف 30–60 FPS على Android | اختبار Playwright 3 دورات تركيب/فك + قياس جهاز فعلي | WebGL leak: `COMPLETED — Verified`؛ جهاز Android فعلي: `UNKNOWN — Requires verification` |
| **العمل دون إنترنت** | تشغيل كامل التطبيق بعد الزيارة الأولى دون اتصال شبكة، وحفظ جميع البيانات في `IndexedDB` و`localStorage` | اختبار Playwright Offline (`context.setOffline(true)`) | تم اختبار SW Offline لمسار ملف واحد بنجاح في المرحلة 2؛ يلزم التشغيل الشامل |
| **سهولة الاستخدام للأطفال** | مساحات لمس لا تقل عن `44×44 px` ويفضل `48–56 px`، نصوص واضحة، ومؤثرات لطيفة | فحص Playwright لـ `boundingBox` | تم التحقق من أساسياته في المرحلتين 1 و2 |
| **أمن الأنواع والجودة** | `tsc --noEmit` بدون أخطاء و`vite build` ناجح دون أخطاء Runtime في الـ Console | `npm run lint && npm run build` | `COMPLETED — Verified` حالياً |
| **حجم الحزمة** | تقليل حجم الـ JS Bundle الأولي وتطبيق Code Splitting لتجاوز تحذير Vite (> 500 kB) | مخرجات `vite build` | `IN PROGRESS` (الحزمة الحالية `1,315.86 kB` — تُحسَّن في المرحلة 14) |
