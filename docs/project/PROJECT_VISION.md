# رؤية المشروع — PROJECT VISION

## 1. الرؤية التربوية
تهدف لعبة **مغامرات لولو ونونو – عالم المعرفة** إلى تحويل وقت الشاشة لدى الطفل العربي (4–10 سنوات) من استهلاك سلبي إلى تجربة تعلم نشطة، آمنة، وممتعة تقوم على:
- **التعلم باللعب والتجربة:** لا تلقين جامد ولا اختبارات عقابية؛ كل خطأ يقابله تشجيع لطيف من لولو ونونو وتلميح بصري تدريجي.
- **المواءمة مع النمو العقلي للطفل:** التدرج من المبتدئ إلى المتقدم عبر نظام الصعوبة التكيفي، بحيث لا يشعر الطفل الصغير (4–5 سنوات) بالإحباط ولا يشعر الطفل الأكبر (8–10 سنوات) بالملل.
- **الاعتزاز باللغة العربية:** تقديم واجهة عربية أصيلة (`RTL`) بخطوط واضحة ومريحة للعين (`Cairo` و`Tajawal`) ونطق بشري سليم مستقبلاً.

## 2. الرؤية البصرية والتفاعلية
- **شخصيات حية وليست صوراً جامدة:** حضور شخصيتي لولو ونونو ثلاثيتي الأبعاد داخل القصة، الشاشة الرئيسية، شاشات اللعب، الفوز، واستعادة النجوم، مع تعبيرات وجه و8 حالات تعبيرية و13 حركة.
- **واجهة مريحة وآمنة بصرياً:** بطاقات مستديرة الحواف، أزرار كبيرة ملائمة لأصابع الأطفال (`min-height >= 44px`), وتباين لوني مريح مع احترام خيار تقليل الحركة (`reducedMotion`).

## 3. الرؤية التقنية طويلة المدى
- **نواة واحدة، منصات متعددة:** بناء تطبيق ويب حديث قابل للتثبيت كـ `PWA` ويعمل بالكامل دون إنترنت، مع جاهزية تغليفه عبر `Capacitor` إلى تطبيق Android مخصص للنشر على `Google Play`.
- **قابلية استبدال الأصول دون كسر المنطق:** تصميم طبقة `assetManifest.ts` و`voiceManifest.ts` بحيث تبدأ النماذج إجرائياً (`procedural-threejs`) وتُستبدل مستقبلاً بملفات `.glb` احترافية أو ملفات `.ogg` صوتية دون إعادة كتابة منطق اللعبة.
