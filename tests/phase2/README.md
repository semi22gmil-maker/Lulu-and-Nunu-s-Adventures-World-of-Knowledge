# اختبارات Playwright للمرحلة الثانية — الشاشات الأساسية وتجربة المستخدم

## الهدف
التحقق التلقائي المتكرر من جميع الشاشات الـ 14 للمرحلة الثانية، والتنقل، وحفظ التقدم محلياً في IndexedDB وlocalStorage، وقفل المراحل والعوالم وبوابة الوالدين، والعمل دون إنترنت (Service Worker)، والاستجابة على شاشات الهاتف (RTL 390×844) وسطح المكتب (1440×960).

## أوامر التشغيل
- تشغيل اختبارات المرحلة الثانية فقط (مع بناء `dist/` وتشغيل `vite preview` تلقائياً):
  ```bash
  npm run test:e2e -- tests/phase2
  ```
- تشغيل جميع اختبارات المرحلتين 1 و2 معاً:
  ```bash
  npm run test:e2e
  ```

## المخرجات المتولدة تلقائياً
- نتائج التنفيذ الفعلية بصيغة JSON: `reports/phase2/qa-results.json`
- لقطات الشاشة الـ 14 الفعلية من Chromium: `reports/phase2/screenshots/01-*.png` إلى `14-*.png`
