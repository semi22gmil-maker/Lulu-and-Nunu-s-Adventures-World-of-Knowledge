# اختبارات التحقق التلقائية للمرحلة الأولى — Playwright (Phase 1 E2E & WebGL QA)

تغطي هذه الحزمة التحقق التلقائي الكامل لشخصيتي **لولو** و**نونو** ومختبر الشخصيات (`Character Lab`) ضد بناء الإنتاج الفعلي (`dist/` via `vite preview`).

## المتطلبات المسبقة

1. تثبيت الاعتمادات:
   ```bash
   npm install
   ```
2. تثبيت متصفح Chromium الخاص بـ Playwright (عند التشغيل على جهاز جديد):
   ```bash
   npx playwright install chromium
   ```
   *(في بيئة الاختبار الحالية أو حاويات Linux يمكن أيضاً تمرير `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` إذا كان Chromium مثبتاً مسبقاً).*

## تشغيل الاختبارات

لتشغيل فحص TypeScript وبناء الإنتاج وجميع اختبارات Playwright (مع إعادة توليد لقطات الشاشة الـ 13 في `reports/phase1/screenshots/` وملف النتائج `reports/phase1/qa-results.json`):

```bash
npm run lint
npm run test:e2e
```

## ما الذي تتحقق منه الاختبارات؟

1. تحميل التطبيق ومختبر الشخصيات دون أخطاء في Console أو JS أو الشبكة.
2. إعادة تحميل الصفحة (`page.reload`) والتأكد من استمرار عمل `Character Lab` والأزرار بعدها.
3. تبديل الشخصيات (`لولو` 19,890 مثلث / `نونو` 13,638 مثلث / `لولو ونونو معاً` 33,528 مثلث).
4. اختبار جميع الحركات الـ 13 لكل من لولو ونونو بشكل مستقل، والتحقق من تحديث الحالة وتغيّر إطارات `<canvas>` والعودة التلقائية إلى `Idle` في نمط `مرة واحدة`.
5. اختبار تعبيرات الوجه الـ 8، `رمش`، `فتح الفم`، ومحاكاة الكلام (`فم + نص`) لكلا الشخصيتين.
6. اختبار جميع التفاعلات الثنائية الـ 9 (بما في ذلك إكمال الخطوات المؤقتة عند البدء من العرض الفردي).
7. اختبار زوايا الكاميرا الأربع، وتدوير الكاميرا 360° بالسحب، وزر `إعادة الوضع الطبيعي`.
8. اختبار أنماط الإضاءة الثلاثة (`استوديو دافئ` / `صباح مشمس` / `مساء هادئ`).
9. اختبار `إيقاف` (`changedPixels === 0`) و`استئناف`.
10. اختبار الاستجابة لتغيير حجم الشاشة (`1440×1180` ← `768×900` ← `390×844`) ومحاكاة اللمس على الجوال.
11. اختبار الاستقرار وأداء ذاكرة WebGL عبر 3 دورات تركيب وفك كاملة (التحقق من ثبات `geometries` و`textures` دون تسريب).

## ملاحظة بيئية

- الاختبارات التلقائية تعمل على Chromium عبر تصيير **SwiftShader (CPU WebGL2)**، وتفصل في التقرير بين هذه القياسات وبين الاختبار على **جهاز Android فعلي (Hardware GPU)** الذي يتطلب جهازاً حقيقياً.
